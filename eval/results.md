## Method

- Each lease runs through the app's own `_run_report_task` (routes/report.py) with the jurisdiction from the ground truth as the user's state choice. Database, PDF and email modules are stubbed out; the Good to Know summary is skipped because it does not affect flags.
- A hit is a flag in the final report whose quoted clause matches a ground-truth excerpt. Matching is one-to-one, greedy by score.
- Match score: the share of the shorter text's distinct word trigrams found in the longer one, after lowercasing and dropping punctuation. Threshold: 0.5. Pairs scoring 0.25 to 0.5 are listed per lease as borderline.
- Citation accuracy compares section numbers (14 DCMR 304.3, D.C. Code 42-3505.51, Va. Code 55.1-1204) in the flag's Source and Law lines with the labeled citation. A section matches its own subsections.
- Precision = hits / (hits + false alarms). Recall = hits / ground-truth clauses. False-alarm rate = false alarms / (hits + false alarms). A flag that matches no ground-truth clause but matches a clause in ground_truth_arguable.csv is reported and not scored.
